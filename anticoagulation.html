Protocol Summary
  • Anti‑Xa management: Start heparin 30 u/kg/hr; check Anti‑Xa at 4h (goal 0.3–0.8). If in range → continue. If out of range → bolus 50 u/kg and increase rate by 20%; recheck in 6h; repeat until in range.
  • Post cath (no stent): If cap refill <3s with distal pulse present and good color → observe. If distal pulse absent → bolus 100 u/kg heparin and recheck in 2h; if still cool/pulseless → repeat 50 u/kg and start infusion 30 u/kg/hr. If still no pulse 4h after starting heparin → follow tPA protocol as above.

Always verify doses, concentrations, and pump programming per local policy. Adjust for clinical factors (bleeding risk, renal function, line patency, etc.).
